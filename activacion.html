Guía de Activación

Sigue estos simples pasos para activar FlowPOS y comenzar a gestionar tu negocio

1

Descargar FlowPOS

Ve a la página de descargas y obtén el instalador para tu sistema operativo.

Ir a Descargas
2

Instalar el Sistema

Ejecuta el instalador descargado y sigue las instrucciones en pantalla.

Haz doble clic en el archivo descargado
Acepta los permisos de instalación
Elige la carpeta de instalación (recomendado: dejar por defecto)
Espera a que complete la instalación (~2 minutos)
3

Abrir FlowPOS

Inicia FlowPOS desde el acceso directo en tu escritorio o menú de inicio.

Primer acceso

Al abrir por primera vez, el sistema crea un usuario administrador por defecto:

PIN: 1234

Rol: Administrador

⚠️ Importante: Cambia este PIN inmediatamente después de activar tu licencia.

4

Obtener Hardware ID

El Hardware ID es único para tu computadora y es necesario para generar tu licencia.

1. Dentro de FlowPOS, ve a Configuración → Licencias
2. Verás tu Hardware ID en la pantalla (ejemplo: a1b2c3d4...)
3. Copia este código o tómale una captura de pantalla

Nota: Este ID está vinculado a tu hardware. Si cambias de computadora, necesitarás una nueva licencia o transferir la existente (solo en plan Enterprise).

5

Contactar Soporte

Contáctanos por WhatsApp con tu Hardware ID y el plan que deseas adquirir.

Información a enviar

Hardware ID (copiado del sistema)
Plan deseado (Trial, Standard, Premium, Enterprise)
Datos de facturación (Nombre/Empresa, RUC si aplica)
Contactar por WhatsApp
6

Recibir Serial Key

Nuestro equipo procesará tu solicitud y te enviará un Serial Key único.

El Serial Key tiene el siguiente formato:

FLOW-XXXX-XXXX-XXXX-XXXX-XXXX

Este código está vinculado a tu Hardware ID y solo funcionará en tu computadora.

7

Activar Licencia

Ingresa el Serial Key en FlowPOS para activar tu licencia.

1. Ve a Configuración → Licencias
2. Haz clic en "Activar Licencia"
3. Pega o escribe tu Serial Key
4. Completa tus datos (Nombre, Email, Empresa, RUC)
5. Haz clic en "Activar"

¡Listo! FlowPOS está activado y listo para usar. Todas las características de tu plan están ahora disponibles.

Preguntas Frecuentes

¿Puedo probar FlowPOS antes de comprar?

Sí, FlowPOS incluye una prueba gratuita de 30 días con funcionalidad completa (plan Trial). No se requiere tarjeta de crédito.

¿Qué pasa si cambio de computadora?

El Serial Key está vinculado a tu Hardware ID. Si cambias de computadora, contacta soporte para obtener una nueva licencia. Los planes Enterprise permiten transferencias ilimitadas.

¿FlowPOS requiere internet?

No. FlowPOS funciona 100% offline. La conexión a internet solo se usa opcionalmente para validaciones periódicas de licencia (cada 30 días por defecto).

¿Puedo cambiar de plan después?

Sí, puedes actualizar o cambiar de plan en cualquier momento. Contacta soporte para gestionar el cambio y te enviaremos un nuevo Serial Key.

¿Qué métodos de pago aceptan?

Aceptamos transferencias bancarias, billeteras electrónicas y efectivo. Contacta soporte para coordinar el método de pago más conveniente.

¿Ofrecen soporte técnico?

Sí, todos los planes incluyen soporte técnico por WhatsApp. Los planes Premium y Enterprise tienen soporte prioritario con tiempos de respuesta más rápidos.

¿Necesitas Ayuda?

Nuestro equipo de soporte está disponible para ayudarte en cada paso del proceso
